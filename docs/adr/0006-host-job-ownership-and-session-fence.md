# 宿主作业归属与会话结束序号围栏

状态：已接受。对应 #17、#20，延续 ADR-0002、ADR-0004 与 ADR-0005。

## 归属与兼容

新 Claude 与 Codex 宿主入口显式传递宿主上下文，作业持久化 `host`、`sessionId`、`workspaceRoot` 和 `ownerSequence`。默认 status、result、cancel（包括指定编号）先核对完整宿主会话归属，再读取日志、恢复或取消。只有 `status --all` 显式查看当前项目全部作业；result 未指定编号时取最近完成的所属作业。未知身份不认领记录。

新宿主后台启动必须先有有效 SessionStart 登记；缺失、损坏、身份不符或序号无效时，在作业淘汰、序号分配和发布前拒绝。前台任务不依赖登记。Codex 首版只支持有主线程钩子登记的身份，未登记的 subagent 编号不能猜测为父线程，也不静默创建登记。

没有宿主上下文的底层 companion 保持旧接口及旧 `claudeSessionId` 原义。只有缺少新归属字段的旧记录才映射 Claude，不映射当前 Codex。两宿主每项目仍共用既有 jobs 锁与50条上限，记录及配套日志一起淘汰。

## 登记与发布顺序

登记位于共享数据根 `hosts/<host>/<会话编号哈希>/session.json`，不参与 `projects/` 迁移冲突。SessionStart 静默保存身份、规范项目根与可空记录来源，不读取记录正文、不输出分派规则；恢复登记保留单调递增的 `lastSequence`、`workspaceRoots` 及未知字段。结束清理不会删除登记或重置计数。

启动作业先取得项目 jobs 锁，并完成可能昂贵的淘汰。随后短暂取得该宿主会话的 owner 锁，在一份原子登记快照中提交递增序号与项目根集合，再发布带该序号的初始作业记录；释放 owner 锁后继续既有 request、worker spawn 与进程实例登记。锁顺序固定为 jobs → owner，owner 锁不跨 spawn 或整树终止。

序号必须先于初始作业记录提交。若中断发生在两次发布之间，只留下不会复用的序号空洞；所有可见的新作业均已被登记计数覆盖。序号缺失或损坏明确报错，不能据时间猜测。

## 无锁结束围栏

真正 SessionEnd 同步只读取已原子发布的登记快照，捕获固定 `{host, sessionId, fence, roots}` 与旧记录的时间截止值，快速启动分离 cleanup helper。该同步路径不等待 owner/jobs 锁、不解析项目、不枚举作业、不查询进程。Stop、回合结束和切换聊天不触发清理。

helper 沿用既有项目 jobs 锁、取消意图持久化、worker 与进程实例核对及整树清理，只处理同归属且 `ownerSequence <= fence` 的作业；不能回读最新计数扩大围栏。同会话恢复后的新作业序号更大，即使时间戳相同或时钟回拨也保留。只有真正旧版、没有新归属及序号字段的记录采用原时间兼容；新记录缺序号、序号损坏或围栏损坏均不能降级。

项目根集合必须与序号同次原子发布。End 读到已预留但尚未发布的序号时，helper 已知道该项目，取得项目 jobs 锁会等待发布完成或持锁进程退出；不能只靠扫描已发布记录发现项目。End 先读取快照时，后续分配的序号必然大于围栏。未知身份与不符的进程实例保持不认领、不误杀；清理失败仍保留记录和取消意图供既有恢复路径重试。

## 钩子与验证

两种宿主各自仅注册 SessionStart、SessionEnd。Codex 使用原生清单显式引用的 `hooks/codex-hooks.json`；插件命令中的 `${PLUGIN_ROOT}` 由 Codex 插件发现阶段替换，走正常 `/hooks` 启用与信任流程。没有 `CODEX_ENV_FILE` 假设。若真实 CLI 验收证明需要独立配置，显式 setup 应保留其他钩子并使用已安装脚本绝对路径，不能直接复制插件占位符。

依据 Context7 `/openai/codex`：主线程 exec 的 `CODEX_THREAD_ID` 对应主线程钩子 `session_id`，标签用于关联；缺失及未登记身份保持未知。依据 `/nodejs/node`：分离子进程须关闭输入、使用独立输出并 `unref()`；复用现有 helper 模式，不新增进程管理体系。

离线验证通过真实 companion CLI、合成钩子和假 dsh，覆盖归属、未知身份、共享50条、固定围栏、同毫秒、时钟回拨、跨项目预留尚未发布、预留后崩溃、登记损坏及旧接口兼容。文件发布竞态由测试预加载夹具控制，不给产品增加测试开关。离线结果不冒充桌面端或 CLI 正常信任流程的实机验收。
